PSXcel (PSX)  -  v0.2.0
=======================

A working Microsoft Excel clone for the original PlayStation, controlled
with a joypad: formulas, charts, themes and memory-card saves.

To run:
  - Boot psxcel.cue in a PS1 emulator (PSoXide, DuckStation, or PCSX-Redux), or
  - burn it to a CD-R and run on a modchipped console.
